# zapiltar-e7.github.io

Personal portfolio, served by GitHub Pages at https://zapiltar-e7.github.io

Plain HTML/CSS/JS — no build step. Edit `index.html` and push.

- **Add a project:** copy an `<article class="card">` block in `index.html`. Set `data-cat` to `mods`, `software`, or both.
- **Use a screenshot instead of the gradient tile:** replace the thumb's text with `<img src="images/your-shot.png" alt="...">`.
- **Add art:** put images in `images/` and replace the placeholder `<figure>` blocks in the Art section.
